# ResumeIQ — Frontend

Next.js + Tailwind + shadcn/ui web client for the ResumeIQ resume screener.

See the [project README](../README.md) for setup, architecture, and full documentation.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Requires the backend API running at `http://localhost:8000` (see root README).
